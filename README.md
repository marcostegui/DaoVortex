# DaoVortex

Builds containerized, portable environments for IoT device development and testing with automated dependency management.

The key benefits of using DaoVortex include:

- Builds containerized, portable environments for
- IoT device development and testing
- with automated dependency management

## Key Features

- Builds containerized, portable environments for
- IoT device development and testing
- with automated dependency management

## Technology Stack

- python
- Standard library, minimal dependencies
- unittest/pytest

## Installation

1. Clone the repository: `git clone https://github.com/vishalrankhamb/DaoVortex.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

To configure DaoVortex, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
